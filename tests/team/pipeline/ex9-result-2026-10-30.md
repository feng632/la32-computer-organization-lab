initial command sequence and a fresh run through `run_ex9.ps1` reproduced the
result. No CPU source was changed by the tests.

Each run compiles into a new temporary directory and checks exact per-case PASS

the control bench has a 20us timeout. Logs from the verified script run are in
`ex9-evidence-2026-10-30/`.

## Program tests: actual IF/ID/EXE/MEM/WB, top and A CSR

Instruction memory is a synchronous test ROM. Data reads use a fixed 32-bit test
word; every data request/store is checked, so an erroneous access cannot hide
behind a permissive memory model. Every debug write is checked by PC, destination,
value and uniqueness (handler instructions may execute once per exception).

| Case | Scenario and result |
|---|---|
| 0 | 66 write checks, 8 exceptions and 8 returns; BREAK with nonzero code; INE on 0xffffffff and zero; ALE on LD.W, LD.H, LD.HU, ST.W, ST.H. Exact Ecode/EsubCode, ERA and BADV checked. Invalid accesses never reach memory. Four legal byte/half/word reads and one final legal store pass. |
| 0, counters | TID written through a real CSR instruction then read through RDCNTID with destination rj; immediate dependency passes. LOW/HIGH expected values captured independently from counter_value before EXE-to-MEM transfer and checked at MEM and WB; LOW immediate dependency and r0 overlapping alias checked. |
| 1 | Software interrupt: enable local/global gates through instructions; interrupt before store; handler clears pending request; original store executes once after return. |
| 2..9 | Each of the 8 hardware interrupt inputs separately; all produce one INT and one ERTN at the expected PC. Testbench removes the external request once INT commits; handler and source are real modules. |
| 10 | One-shot timer configured via CSR instructions, timer interrupt received, handler disables timer and writes TICLR, then returns and executes the paused store exactly once. |
| 11 | Software interrupt pauses CSRWR; no ordinary CSR write at exception commit; after return CSRWR executes once and returns the original zero, followed by readback of 0x123. An early erroneous write would change the returned old value and fail. |

At every exception commit the bench requires no ordinary GPR write, no ordinary
CSR write, correct PC/code/address, and no extra exception after completion.

## Control tests: direct module stimuli (B11/B12)

`tb_ex9_controls.sv` uses the real ID, EXE and MEM. A controlled 64-bit counter
input is used here to exercise nonzero high bits and low-word rollover quickly;
this is not claimed to be A's stable-counter implementation test.

1. Has_int appears and disappears while ID cannot issue: no acceptance during
   the stall, no stale interrupt when the ordinary instruction is released.
2. Older-valid drain with INT: no early issue/deadlock. On actual acceptance,
   real EXE registers the INT; lowering has_int afterwards cannot cancel it.
3. Injected IF ADEF survives placeholder-zero INE decoding; INT takes priority
   over the same pending IF exception. This checks B's reception/priority only,
   not C's actual ADEF generation.
4. INT cancels an ID branch redirect.
5. INT removes the CSRWR metadata task.
6. INT removes the ERTN metadata task.
7. LOW reading waits behind a full MEM while the provided counter advances
   across a low-32-bit rollover, samples only on transfer, then holds during
   four blocked MEM cycles; EXE/MEM placeholder forwarding is disabled.
8. HIGH reading similarly samples nonzero 0x12345679 and holds under backpressure.
9. Incoming INT survives an unaligned-load ALE candidate and suppresses its
   data request.

## Scope limits

- No course ex9 full image or reference trace comparison was run.
- Actual IF ADEF generation remains C's responsibility; only an injected IF
  exception was checked here.
- Divider modules are rejecting guards from `tb_ex8_smoke.sv`: any division
  request fails immediately. These ex9 benches do not validate real division.
  The previously recorded real-divider cancellation test is separate.
- Timer case covers end-to-end one-shot interrupt handling, not all periodic,
  reconfiguration or simultaneous-TICLR boundary combinations in A's matrix.
- No bit build, online evaluation, synthesis or timing result is claimed.
- These directed tests are evidence for the listed cases, not proof that every
  possible instruction/stall/interrupt combination has been exhausted.
