# 来源、要求与团队选择

## 1. 课程来源

- 《计组课设指导书LA版-2025.pdf》印刷页25～33：异常中断与CSR；印刷页35～36：个人/团队分阶段要求。
- 《计算机组成原理课程设计说明LA+2026.pptx》第10页：团队创新基础两阶段；第11页：分支预测、Cache、外设创新扩展。
- 课程`for_test_obj/ex8_obj/test.s`含n47_syscall_ex_test；ex9镜像进一步含n48～n58。仅静态存在函数标签不证明入口实际运行过。
- 本仓库固定基线的真实EXE/WB/IF、头文件与ex7验收/构建记录。

这些材料已用于核对本规范，课程文件本身不随本次发布上传。哈希在baseline.json。组员需要自行取得课程指令编码手册；新版架构手册不能替代课程特定版本的全部编码。

## 2. 官方参考

- [LoongArch官方基础架构手册](https://loongson.github.io/LoongArch-Documentation/LoongArch-Vol1-EN.html)：CSR访问、异常提交/返回、异常优先级、CSR编号及控制字段。不同版本新增功能不自动成为本课程要求。
- [AMD Divider Generator PG151](https://docs.amd.com/v/u/en-US/pg151-div-gen)：ARESETN有效持续时间与释放后的恢复周期；NonBlocking输入配对与输出有效。

在课程子集之外，不据现代手册扩展MMU、TLB、向量中断、核间中断或浮点异常。

## 3. 明确属于团队设计的选择

WB统一CSR访问、保守序列化、164位并行元数据、无额外握手CSR接口、IF缓存重定向、除法双IP复位取消、软件可见未规定状态确定性复位，以及分支和测试目录组织，均为本团队选定的实施方案。它们不是“原ex7已经具备”的功能，也不是架构唯一实现方法。

计时边界以课程指导书timer_cnt==0路径为设计依据，04明确逐拍要求；与实际参考出现差异时留存证据并按接口变更流程处理。

## 4. 与原三人初步方案的关系

保留A/B/C持续负责到ex9、尽早最小闭环、负责人自测及C持续集成。补充固定接口与副作用保护；把“每次完整回归ex1～7”改成相关测试加阶段覆盖核对；把“异常不能写CSR”明确成禁止普通指令写入，异常硬件更新仍必须执行。
